# Immutable edge-window ownership

shodo-c91.2 replaces deep-copy cache read handles with private immutable Arc tuples. Read-only validation and right probes keep shared handles; only a selected final EdgeOverlay converts to independent owned vectors. A miss preserves the original owned result and makes one len-sized immutable cache snapshot, as the original miss path did; uncacheable edited/dirty/saturated/oversized results remain on the allocation-free owned-handle path. Exclusive shared handles move their vectors after eviction; otherwise the selected result makes the necessary copy. Public layout/output APIs and sharing visibility are unchanged.

The original paragraph identity, range/glyph-budget key, warning/saturation eligibility, request charge before hit,256-entry/32768-cost/1024-oversize gates and clear/shrink semantics remain. The retained snapshot clones all nine GlyphStore vectors and runs at their lengths, preserving the old cache capacity contract. Original growing miss vectors stay in the owned output; no per-miss shrink/realloc is introduced. Arc headers and the smaller map-value representation remain real measured costs; original insert copies often also supplied an eventual selected result, so shifting that necessary copy is not counted as removing every miss copy.
