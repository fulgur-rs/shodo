# SHODO-41: shared indexed line widths

The normal scan, selected break plans, narrower/float retries and ruby range
queries now use `line::range` geometry and edge completion. The scan cursor
reads the paragraph's unit advances and keeps sparse cumulative tab and clipped
cluster deviations locally, so ruby re-entry cannot replace the live scan's
state. Unit effects are charged once; selected output moves its measured widths
instead of re-shaping or repeating atomic warnings. The previous selected
implementation remains only as a test oracle.

The work started at `a5c0bf8`. Upstream `ead4063` changes release permissions
only and is incorporated before publication. No public API or dependency change.

## Regressions and review decisions

- The first new test failed because normal lines built zero indexed units.
  Normal and ruby tab origins now share the unit table without sharing tab steps.
- Independent review found duplicate missing-atomic warnings. The regression
  failed with two warnings; cursor selection now reports exactly one.
- Retained float retry after `LayoutContext::shrink_to(usize::MAX)` failed with
  a missing range-index key. Retry restores the paragraph indexes while retaining
  the already-measured cursor.
- A preserved space followed by 1,024 absolute anchors made 525,825 obstruction
  visits. Obstruction is now indexed by boundary in linear time; the regression
  bounds remaining visits by four times the unit count.
- Saturating sequential advances followed by signed margins gave a normal tab
  width result of 20,000,008 px versus the indexed 20,000,040 px. Tab positions
  now use the same wide prefix arithmetic as range queries. All individual
  supplied lengths in the fixture are within the 10,000,000 px sanitizer cap.
  Extreme signed advances intentionally use the existing range model's canonical
  arithmetic consistently, replacing the previously divergent sequential model.
- A clipped ligature followed by a selected hyphen, with window/glyph limits
  and a one-warning cap, retained the wrong first warning. Planned selections
  now measure the hyphen before clipped unit producers, preserving the original
  order. The test sweeps window caps 1/2/4096, glyph caps 0/1/2 and warning caps
  1/2/16 against the independent oracle, including content and unit widths.
- Fixed-revision independent paragraph selections release prior range indexes;
  clipped cursor selection preserves oracle geometry, warning and reshape effects.
- Retry moves its cursor out and back instead of cloning the full sparse prefix.

The independent reviewer confirmed no remaining important findings after the
final warning-order fix.

## Follow-up: cold/interleaved short-line work

GitHub review thread `PRRT_kwDOUsVfT86seE51` identified that the first width
cursor eagerly rebuilt the entire paragraph. Starting from `da6fb1e`, the new
regression failed: a two-unit line in an 8,192-unit paragraph built all 8,192
units. Switching between independent paragraphs repeatedly discarded those
indexes, and `max_graphemes=1` paid the same full suffix work.

The fix prepares one immutable width index during paragraph finalization:
static advances (excluding caller atomic sizes), visual spacing, trailing
whitespace and obstruction tables. Each paragraph owns that index. Normal and
planned cursors borrow it and measure only visited atomic, tab and clipped
cluster deviations. Scalar queries share the same static index and retain a
sparse atomic prefix per revision; they enumerate atomic positions only once
per revision rather than per width query. Both paths use the same geometry and
completion, with their existing scalar/planned producer warning order.

Retained memory is now linear in each live paragraph's admitted units, including
the balanced spacing tree and width/whitespace prefixes. Context revision/root
changes hold only shared ownership of that static index plus mutable scalar
prefixes. No full table cloning or full atomic enumeration occurs at normal
cursor startup. The static tables follow the existing finalized spacing/unit
admission contract; `max_analysis_bytes` still accounts logical analysis
admission rather than finalized width/spacing tables or process RSS. Explicit
context shrink drops scalar/metric/neighbor caches; immutable width tables stay
with live paragraph owners. No public limit or dependency was changed.

Index preparation retains unit saturation for selected-range replay without
emitting build warnings. The saturating-unit fixture explicitly verifies that
preparation does not warn; existing cold/warm saturation golden records remain
unchanged. Paragraph-shared test-only range-query counters use relaxed atomics,
so the immutable tables remain safe to share across layout contexts/threads.

GREEN evidence: the regression covers two and three interleaved paragraphs,
ordinary short lines and `max_graphemes=1`, for 24 rounds each. Every call
advances at most 16 cursor units and performs no whole-paragraph rebuild.
The range suite passed 22 tests after the ownership change. The full default
library suite passed 1,027 tests with 8 ignored; formatting and diff checks pass.
The parent performs final workspace/CI lint validation at the resulting commit.

No new raw log files or scratch directories were created for this follow-up;
commands wrote to their tool output and reused the existing task target.
