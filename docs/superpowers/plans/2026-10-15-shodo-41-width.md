# SHODO-41 width implementation plan

> **For agentic workers:** Use superpowers:executing-plans for this domain; SHODO-42 is delegated independently through superpowers:dispatching-parallel-agents.

**Goal:** One indexed width function for main lines and ruby ranges.
**Architecture:** Split `range::width` into natural range measurement and edge
completion. Use a common selected-line constructor from scan, plan and retries.
**Tech Stack:** Rust 2024; existing fixed-point geometry and spacing RangeIndex.
**Spec:** `docs/superpowers/specs/2026-10-15-shodo-41-width-design.md`.

## Global constraints

- No public API or dependency changes; Rust 1.89 remains supported.
- Preserve selected glyphs, break reasons, warnings and budget behavior.
- Task scratch uses `~/tmp`; remove owned scratch after evidence is recorded.

## Review focus

- Tabs include offset, indent and cloned start decoration; scan-local tab prefixes include that origin; scalar query state stays separate.
- Atomic revision changes rebuild indexed advances.
- A discretionary hyphen is added only when the chosen break requests it.
- Preserved whitespace behind a closing edge stays visible to fit tests.
- Clipped shared clusters and bounded edge shaping have cold/warm equivalent effects.
