# Ruby Formatting Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking. Execute inline and request one fresh whole-branch review at the end.

**Goal:** Implement all of shodo-unc.3: source-preserving paired ruby, coordinated wrapping, alignment/position/overhang, half-leading-aware metrics and vertical output.

**Architecture:** Import base content into the ordinary parent input while retaining ruby boundaries. Shape annotation snapshots separately and attach indexed immutable pairing/cut tables. Candidate and accepted line formatting use the same ruby measurements; accepted annotation Lines retain their glyph/font/source data for nested caller painting.

**Tech Stack:** Existing Rust, ICU, harfrust, skrifa, unicode-bidi and fixture tiny-skia. No new core dependency.

**Spec:** docs/superpowers/specs/2026-09-28-ruby-design.md

## Global Constraints

- Rust 1.89.0, stable, wasm and existing feature combinations remain supported.
- No new core dependency is required.
- Preserve ordinary non-ruby behavior, public glyph ownership and the original font fixtures.
- Annotation strings never enter Paragraph::text or its primary OffsetMapping.
- All retained base/annotation text, items, styles and shaped glyphs count against the parent's aggregate Limits, including first-line alternates and nested ruby.
- BreakToken remains cheap and retry-safe: its parent unit cursor identifies immutable lane cuts, not mutable annotation state in LayoutContext.
- Do not depend on, change or merge the raikiri spike.

## Review Focus

1. Different sources share a ligature/ZWJ cluster inside a ruby box: no duplicated glyphs or lost source slices; pinned by Task2 shared_cluster_source_slices and Task5 ruby_dom_split_selection.
2. Several annotation levels with different legal break counts: a continuation consumes every lane once and retry is pure; pinned by Task2 monotone_multi_level_cuts and Task3 multi_level_continuation_retry.
3. First-line transform expands base text while annotation styles also change: cut mapping, widths and second-line continuation use the correct set; pinned by Task3 first_line_ruby_source_cuts and Task5 first_line_annotation_sources.
4. Nested ruby and reused input snapshots multiply retained storage: aggregate limits fail before excessive allocation; pinned by Task2 aggregate_nested_limits and long_ruby_cut_index_is_linear.
5. VerticalLr over/under differs from logical block-start/end: output matrix, hit and PNG bounds must agree; pinned by Task4 vertical_ruby_line_relative_positions and Task6 ruby_vertical_pixel_bounds.

- src/ruby/mod.rs: public inputs/enums/errors, views and exports; short coordination surface.
- src/ruby/input.rs: immutable snapshots of builder input and structural validation.

- src/ruby/builder.rs: base import, remapping and retained ruby boundary metadata.
- src/ruby/prepare.rs: annotation Paragraph construction, aggregate accounting and parent-set links.
- src/ruby/cuts.rs: indexed monotone safe lane correspondence.
- src/ruby/measure.rs: candidate widths shared by ordinary/intrinsic/planned selection.
- src/ruby/align.rs: per-fragment base/annotation alignment without changing shaper advances.
- src/ruby/place.rs: line-relative placement, overhang, annotation Lines and metric contribution.
- src/ruby/hit.rs: annotation-local hits and base routing.
- src/ruby/tests/: focused internal input/pairing/cut/measure/metric/limit tests.
- dev/fixtures/tests/ruby_input.rs, ruby_layout.rs, ruby_geometry.rs, ruby_sources.rs, ruby_paint.rs: public real-font contracts.
- dev/fixtures/examples/ruby_png.rs and docs/ruby.md: real rendering example and caller contracts.
- Existing builder/analysis/paragraph/line/output/hit/accessibility modules: narrow integration hooks and exhaustive consumer updates.
