# Single-pass font-run feature construction

Complete shodo-sbp.11 after shodo-sbp.10. Current font/coordinate resolver constructs style features which shape_items replaces with item-specific features; its other production consumers only read coordinates and size. Remove feature construction from that resolver. Keep shape_items responsible for the final item features, including missing-font output. Build upright prefixes and CSS/author features into the same Vec without an intermediate style Vec. Preserve exact order: optional automatic width first, vertical defaults/vkrn next, CSS components, explicit author settings last. Horizontal/sideways/combined have no automatic vertical prefix.

Private functions only; no public API, dependencies, limits, fixtures or saved spikes change. Public source mappings, glyphs and geometry, warnings, variation/size-adjust and retained inputs must remain identical. Performance is not a blocker for raikiri/S4. Time, gross, net, peak are separate; RSS not measured.

A fixed Latin/CJK public paragraph probe compares default and feature-rich styles, single long and many short styled runs, horizontal/upright/combined/automatic-width cases. Fonts and versions frozen, system discovery off. Immutable counter-free timing, allocation-only and feature-construction-only executables; warmup plus ABBA after builds. Signatures include text/source mapping, complete glyph/line geometry and warnings. Feature-rich style sets kerning/ligatures and explicit repeated tags; alternating size/feature values forces distinct runs. Report actual feature-construction counts and all costs, not an assumed speedup.

Tests: coordinate/metric resolution invokes zero feature constructions for a feature-rich style (resource RED1→GREEN0); direct item-feature tests assert literal ordered tags/values for horizontal/upright/combined/sideways and width with explicit overrides. Existing tiny shaping windows retain one instance. Dedicated exact A/B and standard54 matrix against sbp10-variable-matches, required workspace/no-default/complex/fmt/clippy/docs/fixed snapshots. One final fresh whole-branch Astra review, one Important/Critical RED/GREEN fix pass, Minor deferred, user-authorized PR/latest-head CI/merge/close/owned-tree cleanup.
